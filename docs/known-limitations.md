# Known limitations

- v5 룰테이블의 D+0~~7은 팀 잠정값이고 D+8~~14는 외삽값이며 임상 검수가 필요합니다.
- 피코토닝 한 종류만 지원합니다.
- 제품 성분 데이터베이스나 자동 성분 추출을 제공하지 않습니다.
- local 모드는 기기·브라우저 간 동기화와 백업을 제공하지 않습니다.
- Supabase 계정 저장은 사용자별 JSONB 한 행을 사용하는 MVP 구조이며, 여러 기기의 동시 수정 병합은 지원하지 않습니다.
- 카카오·Supabase 운영 설정이 없으면 로그인 UI는 비활성이고 기존 local 모드로 동작합니다.
- 사진 업로드·분석과 알림은 비활성입니다.
- 제품 검색·바코드·OCR·전성분 자동 매칭은 제공하지 않습니다.
- 커머스 상품은 실제 추천이 아닌 명시적인 데모 fixture입니다.
- 제품 추천 화면(`/recommendations`)은 룰테이블과 제품 데이터베이스가 갖춰질 때까지 어떤 화면에서도 연결하지 않습니다.
- D+15 이후에는 룰테이블 범위를 벗어나 D+14 판정이 그대로 유지됩니다.
- 시술 기록은 한 건만 보관하며, 새 시술을 등록하면 이전 시술일을 대체합니다.
