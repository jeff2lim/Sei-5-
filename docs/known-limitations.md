# Known limitations

- v5 룰테이블의 D+0~~7은 팀 잠정값이고 D+8~~14는 외삽값이며 임상 검수가 필요합니다.
- 피코토닝 한 종류만 지원합니다.
- 제품 성분 데이터베이스나 자동 성분 추출을 제공하지 않습니다.
- local 모드는 기기·브라우저 간 동기화와 백업을 제공하지 않습니다.
- Supabase 저장소는 RLS 설계 전 의도적으로 비활성입니다.
- 사진 업로드·분석과 알림은 비활성입니다.
- 제품 검색·바코드·OCR·전성분 자동 매칭은 제공하지 않습니다.
- 커머스 상품은 실제 추천이 아닌 명시적인 데모 fixture입니다.
- 기록 달력은 현재 월 보기만 제공합니다.
