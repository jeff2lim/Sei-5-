# 회복노트 룰테이블 v6 적용 범위

v6는 피코토닝 전후 D−7~~D+14를 결정론적으로 판정합니다. D−7~~D−1 준비기는 다음 시술일을 등록한 경우에만 활성화되며, 회복기·재개기 판정보다 준비기 판정이 엄격할 때만 게이트가 적용됩니다.

## 포함된 범위

- D+0~14 회복기·재개기 41개 원본 타임라인과 3개 민감도 전개
- D−7~D−1 준비기 36개 원본 타임라인과 `prep_gate` 민감도 전개
- 7일·14일·21일·28일 시술 주기 겹침 처리와 `prep_gated` 사유
- `unknown` 독립 채널과 고정 안전 문구
- 하이드로퀴논·벤조일퍼옥사이드·트레티노인·아다팔렌 매칭 제외 및 의약품 안내
- 판정을 바꾸지 않는 병용 9쌍과 민감도별 자동 `active_from_d`
- 준비기 행동 경고 5개와 consult 온보딩 플래그 처리
- 증상 하향, 경고 신호 부분 정지, 선크림-세안 제거력 결합

## 생성 산출물

`pnpm rules:build`는 다음 파일을 만듭니다.

- `build/rules.generated.json`: 회복기 123개·1,845셀, 준비기 108개·756셀
- `build/combinations.generated.json`: 3개 민감도 × 9쌍

원본은 `data/timelines.json`, `data/prep_timelines.json`, `data/combinations.json`이며 생성 파일을 직접 편집하지 않습니다.

## 검수 우선순위

`pnpm rules:validate`가 `needs_review`, `pending_removal`, 구현 드리프트, 제외 의약품, D+14 클램프 목록을 별도로 출력합니다. 특히 비타민C, AHA/BHA, 미백 기능성, 스크럽 준비기와 `acne_active` 존폐를 먼저 검수해야 합니다.

이 룰테이블은 진단이나 치료 추천이 아닙니다. 경고 신호가 있어도 보습·진정·자외선 차단은 유지하고 자극 제품과 메이크업만 부분 정지합니다.
