# 회복노트 룰테이블 v5 적용 범위

이 구현은 `codex_ruletable_spec_v5.md`의 확정 표를 코드의 단일 원본 데이터로 옮긴 것입니다.

## 포함된 범위

- D+0~14 회복기/재개기 전개
- 정상·낮음·높음 민감도 정책과 D+14 클램프
- 14개 판정 성분군, 병원 제공 제품 consult 채널, 향료 advisory
- 14개 성분군의 대표 이명 3개와 전체 이명 사전
- 세안 10종, 자외선 차단 4종, 베이스 7종, 독립 제형 5종
- 제품 판정의 성분/제형 보수적 결합과 판정 사유
- 세정 제거력, 선크림·메이크업 레이어링과 세안 가능 여부
- 회복 경과 5개와 경고 신호 4개의 2단 증상 모델
- 자극/기능성 한 단계 하향, restorative·자차 제외, 경고 신호 부분 정지
- 행동 경고 문구의 날짜별 노출과 자동 소멸
- 기존 v0.1 localStorage 제품 ID 마이그레이션 어댑터

## 상태와 검수

원본 타임라인은 41개이며 세 민감도로 전개하면 123개 타임라인, 1,845개 일별 셀이 생성됩니다.

- D+0~7: `team_provisional`
- D+8~14: `extrapolated`
- 와이어프레임 v20 불일치 8개: `needs_review`
- 높은 민감도에서 D+14 이후로 밀리는 4개: `deferred`

`sun.waterproof_stick.normal`의 D+7 `stop` → D+8 `go` 직접 전이는 일반 전이 경고 대상이지만, v5의 세정 커플링 확정 표를 그대로 보존한 의도된 예외입니다.

## 안전 경계

이 룰테이블은 진단이나 치료 추천이 아닙니다. 경고 신호가 있어도 미온수 세안·보습·진정·자외선 차단은 유지하고, 자극 제품과 메이크업만 부분 정지합니다. 병원 연락은 고정 안내 문구이며 병원 연동이나 전화번호 데이터베이스는 없습니다.
