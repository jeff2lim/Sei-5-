# Privacy data map

| 데이터 | 목적 | 저장 위치 | 분석 이벤트 | 삭제 |
| --- | --- | --- | --- | --- |
| 시술일 | D+n 계산 | 브라우저 localStorage | D+n만 전송 가능 | 전체 삭제 |
| 민감도 선택 | 안내 문맥 | 브라우저 localStorage | 전송 안 함 | 전체 삭제 |
| 제품명 | 사용자 식별 | 브라우저 localStorage | 원문 전송 금지 | 제품/전체 삭제 |
| 제품 속성 | 룰 평가 | 브라우저 localStorage | 속성 개수만 | 제품/전체 삭제 |
| 체크 답변 | 행동 안내, 기록 | 브라우저 localStorage | 선택 개수와 행동만 | 전체 삭제 |
| 사진 | 현재 비활성 | 저장 안 함 | 전송 안 함 | 해당 없음 |
